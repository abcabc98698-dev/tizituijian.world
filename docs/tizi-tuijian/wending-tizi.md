### 1. TCP 拥塞控制算法下的吞吐量雪崩公式
根据经典的 Mathis 吞吐量公式，TCP 连接的最大传输速率受到往返时间（RTT）与丢包率（$p$）的刚性制约：

$$Bandwidth \le \frac{MSS}{RTT} \times \frac{C}{\sqrt{p}}$$

其中 $MSS$ 为最大报文段长度，$C$ 为比例常数。当丢包率 $p$ 从平时的 $0.1\%$ 飙升至晚高峰的 $25\%$ 时，**实际可用带宽会呈非线性断崖式下跌 90% 以上**。即使你的梯子白天能跑 500Mbps，晚高峰在公网丢包压迫下也会连 1080P 都无法流畅加载。

## 四、如何用 MTR 工具自测你当前梯子的稳定性

如果你怀疑当前使用的梯子存在暗中偷跑丢包或线路造假，可在终端运行 MTR 进行逐跳链路诊断：

```bash
# 在 Linux / macOS 终端或使用 NextTrace 工具检测专线落地跳数
mtr -n -c 100 --report 1.1.1.1
```

**判别标准**：
- **真正的专线**：从境内入口机房跃点之后，直接跳入境外核心交换节点（中间跳数极少，且第 2~4 跳之间绝对不出现公网 202.97.*.* 骨干路由与丢包记录）。
- **假专线/公网套皮**：在第 3~6 跳出现明显的公网 AS 节点，且伴随 15% 以上的丢包率与数百毫秒的时延抖动。

## 五、稳定性常见疑惑解答 (FAQ)

### Q1：为什么有些便宜机场白天测速有 500Mbps，一到晚上就彻底瘫痪？
因为白天中国国际出口总带宽利用率不足 40%，公网出口畅通，便宜中转甚至直连也能跑出漂亮的数据；但到了晚高峰，公网出口发生严重拥塞，ISP 路由器优先保障企业高优先级专线流量，公网民用流量遭到丢包抑制。白天的测速图对晚高峰表现没有任何参考价值。

### Q2：专线梯子价格普遍比公网直连贵，贵在哪？
正规 IEPL/IPLC 跨境专线是向电信、联通或移动运营商按兆宽带月租采购的实体物理光纤，采购成本通常在 **¥150~¥250 / Mbps / 月**。服务商必须持续投入重资产维持带宽冗余，因此专线梯子成本结构透明，无法像超售公网 VPS 那样做到几块钱卖几百 G。
