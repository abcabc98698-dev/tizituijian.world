## 一、机场对设备数限制的三大底层技术机制

很多用户以为「多设备限制」是指安装了几个 App，实际上服务商后台是通过以下机制在接入层进行网关鉴权的：

```
[ 机场网关层并发与设备数审查模型 ]

客户端发起代理连接
        │
        ▼
机场边缘接入网关 (Border Gateway)
        │
        ├── 机制 1: 在线公网 IP 数审计 (Online Public IPs)
        │     例如: 限制 2 个 IP。你家里宽带算 1 个 IP，手机 4G/5G 算第 2 个 IP。
        │     若室友用宿舍宽带同时连接 (第 3 个 IP) ───> 触发阻断，踢掉最先连接者或全员断网
        │
        ├── 机制 2: TCP/UDP 活跃连接并发数审计 (Active Concurrent Connections)
        │     限制单账号并发线程上限 (如 500 个并发连接)。多设备同时看视频会导致线程溢出
        │
        └── 机制 3: 订阅链接请求频率风控 (Subscription Fetch Rate Limit)
              多台设备短时间内频繁刷新订阅链接，触发 Cloudflare WAF 封锁拉取
```

## 四、多人/多设备合租的最优技术解决方案：部署软路由

如果是在同一个家庭、宿舍或办公室网络内有多台设备需要翻墙，**最聪明的做法不是每台设备都装 App，而是部署一台软路由（OpenClash / PassWall）**：
1. **对外只占用 1 个 IP 额度**：在机场网关看来，整个局域网的所有设备流量均被软路由聚合为局域网网关的单个公网 IP 发出；
2. **全屋设备无感翻墙**：Switch、PS5、Apple TV、智能音箱等无法安装客户端的设备，连接局域网 Wi-Fi 即可直接畅游海外网络；
3. **极大节省账号成本**：只需购买一个普通单人套餐，即可通过软路由供给全家十几台设备同时高速使用。

## 五、按人数选型常见问题解答 (FAQ)

### Q1：我可以把订阅链接分享给不同城市的朋友一起用吗？
绝对不要这样做！绝大多数机场严厉禁止「跨地域异地多 IP 同时并发」。如果系统检测到 1 秒钟内同一个账号在广州电信和北京联通同时发起连接请求，会立刻判定为「账号被盗或恶意公开倒卖」，直接触发永久封号且无法退款。

### Q2：为什么软路由翻墙后，有些设备的网速变慢了？
因为软路由在进行大规模数据包的解密与分流时，会占用大量 CPU 资源。如果使用几十元的廉价老旧路由器刷机，其单核性能无法支撑 500Mbps 的高吞吐解密。建议选购 Intel N100 等现代 x86 架构软路由以跑满物理专线。
