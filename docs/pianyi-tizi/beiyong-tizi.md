## 四、在 Clash Verge Rev 中配置「自动故障转移（Fallback）」

利用开源客户端的策略组语法，无需手动切换即可实现毫秒级自动容灾：

```yaml
# Clash Verge 策略组配置示例
proxy-groups:
  - name: "🚀 高可用容灾节点组"
    type: fallback
    url: "http://www.gstatic.com/generate_204"
    interval: 60       # 每 60 秒检测一次节点可用性
    tolerance: 50      # 延迟容差阈值 (ms)
    proxies:
      - "光速云-香港01-IEPL"      # 主线路 (优先走此节点)
      - "微风网络-香港01-IEPL"    # 备用线路 1 (主节点挂掉后自动无缝接管)
      - "飞猫云-备用节点"         # 备用线路 2 (终极托底)
```

## 五、备用梯子搭建常见问题解答 (FAQ)

### Q1：为什么不能把同一个机场的不同节点当作主备？
如果两个节点属于同一个机场品牌，它们通常共用同一个境内的 BGP 入口机房、或者共用同一套域名解析托管服务。一旦该机场的入口遭遇国内网络故障或域名遭到 DNS 污染，**其名下的所有节点会瞬间集体变红超时**。真正的双线路热备必须采用**不同品牌、不同入口机房、不同技术架构**的完全物理隔离服务商。

### Q2：备用梯子平时不怎么用，会被商家停用账号吗？
正规的大牌机场只要套餐在有效期内，绝不会因为用户长时间不使用而清理账号。但在购买不限时按量包时，建议每隔 2~3 个月手动连接测速一次，确保客户端内的订阅链接处于最新同步状态。
