# 评测方法论与实验室标准 (Methodology)

为了保证全站评测结果的严谨性、客观性与工程可复现性，**tizituijian.world** 制定了标准化的《跨境网络服务质量综合评估规约》。本规约对所有收录品牌的测试环境、量化指标和评分权重进行了严格界定。

---

## 一、四大核心评估维度与加权模型

我们采用百分制量化加权算法，综合得分由以下四大维度组成：

| 评估维度 | 权重占比 | 核心考察指标 | 测试方法与工具 |
| :--- | :---: | :--- | :--- |
| **1. 线路稳定性与可用率** | **35%** | 24小时断流率、晚高峰丢包率、Ping 延迟抖动 (Jitter) | 自建分布式探针每 5 分钟 ICMP/TCP 握手监测 |
| **2. 晚高峰吞吐与有效带宽** | **25%** | 20:00~23:00 4K/8K 视频缓冲首屏延迟、Speedtest 实测下行带宽 | iPerf3 多线程并发测速、YouTube 4K Stats for nerds |
| **3. 协议先进度与AI/流媒体解锁** | **20%** | ChatGPT/Claude 洁净度、Netflix/Disney+ 落地住宅IP原生解锁率 | 自动化 IP 纯净度检测脚本、跨地域流媒体解锁探针 |
| **4. 客户端体验、性价比与售后** | **20%** | 多端免配置自研 App、月付套餐门槛、工单平均响应时长与 TOS 退款合规 | 实际充值开箱、模拟小白用户多端安装、提交售后工单 |

## 二、测试环境与网络基准

所有入库品牌的基准测试均在以下标准化物理环境下执行：

1. **三网物理专线基准**：
   - 电信节点：上海千兆 FTTH 直连光猫，测试 AS4134 与 CN2 跨境路由。
   - 联通节点：北京千兆 FTTH 直连光猫，测试 AS4837 与 AS9929 跨境路由。
   - 移动节点：广州千兆 FTTH 直连光猫，测试 AS9808 与 CMIN2 跨境路由。
2. **测试时间窗口**：
   - 基础对照组：工作日白天 10:00 - 16:00（轻载网络环境）。
   - 核心极限组：周五至周日 **晚高峰 20:00 - 23:30**（全国骨干网出境光缆重度拥塞时段）。
3. **软硬件配置**：
   - 终端硬件：Intel Core i7-13700K / 32GB RAM / 2.5GbE 有线网卡。
   - 内核协议：Clash Meta (Mihomo) 最新稳定版内核、Sing-box 最新稳定版内核及品牌官方自研客户端。

## 三、关键指标测试与判别标准

### 1. 晚高峰丢包率（Packet Loss）分级判准
- **优秀 (A+)**：丢包率 `< 1.0%`。无论网页打开还是音视频通话均毫无感知，属于高品质企业专线。
- **良好 (A)**：丢包率 `1.0% - 3.0%`。4K 视频偶有 1 秒微小卡顿，网页加载极速。
- **及格 (B)**：丢包率 `3.0% - 8.0%`。文字交流顺畅，大流量下载或高清视频有明显缓冲。
- **高危 (F)**：丢包率 `> 10.0%`。频繁出现 TCP 握手重传、客户端掉线甚至无法连接，评测页面予以黄牌警告。

### 2. AI 生产力工具可用性（AI Cleanliness）
针对 OpenAI (ChatGPT)、Anthropic (Claude) 以及 Google Gemini 等严苛风控平台：
- **原生住宅/机房洁净 IP**：直接直连成功，无需频繁刷新 Cloudflare 5 秒盾与图像验证码。
- **受污染机房 IP**：出现 `Access Denied 1020` 或强行要求验证手机号，该品牌在此子项扣分。

### 3. 流量倍率真实性核查
部分劣质机场标榜“1元100G”，实际节点暗中设置为 **5倍率或 10倍率**，导致用户看 10GB 视频即被扣减 100GB 额度。我们的评测脚本会使用标准 1GB 二进制文件进行传输，对比前后后台扣量数值，一旦发现虚标立即在文章中公开曝光。

## 四、动态复测与更新机制

代理服务具有高度流动性。我们制定了以下保障机制：

1. **每月周期性自动化扫描**：定期跑通节点存活与解锁状态。
2. **季度人工全面复核**：由资深工程师重新采购当季主流套餐，重新跑全套测试矩阵。
3. **读者反馈联动**：若读者社区出现连续 3 起以上关于某品牌的线路跑路或长时间断流反馈，我们将立即启动临时专项测试并在页面添加风险提示。
