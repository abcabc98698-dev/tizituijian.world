## 一、原生 IP vs 广播 IP 的底层鉴别机理

```
[ 落地 IP 属性审查与识别全景图 ]

落地 IP (Target Node IP)
           │
           ▼
查询全球权威 IP 数据库 (MaxMind GeoIP2 / IP2Location / IPinfo)
           │
           ├── 维度 1: 注册所在地 vs 实际宣告地 (Native vs Broadcast)
           │     • 原生 IP (Native IP): 注册在香港/美国本地，且在当地机房物理宣告

           │
           └── 维度 2: IP 类型标注 (ASN Usage Type)
                 • Hosting / Data Center (廉价机房 IP): 欺诈评分 > 80，流媒体/AI 直接阻断
                 • ISP / Residential (原生住宅 / 家宽 IP): 欺诈评分 < 10，享有最高信任特权
```

## 四、如何查询你当前梯子节点的真实 IP 属性

在连接代理后，访问权威检测平台进行全方位体检：
1. **检测欺诈度（Fraud Score）**：访问 `scamalytics.com` 或 `ipqualityscore.com`，输入当前节点 IP，若 Fraud Score 高于 50，说明该 IP 处于高风险黑名单中；
2. **检测原生与广播属性**：访问 `bgp.he.net` 查看当前 IP 所在的 ASN 组织名称，确认是否为本地正规电信运营商（如 HKT、HKBN、NTT、AT&T）。

## 五、原生 IP 常见问题解答 (FAQ)

### Q1：为什么原生住宅 IP 普遍价格稍高？
因为真实海外家庭宽带住宅 IP（Residential IP）是向海外本地电信运营商直接租用的实体宽带端口，资源极其稀缺，不可批量虚拟复制；而机房广播 IP 可以花极少的钱向云主机商批发数万个。一分钱一分货，住宅 IP 的纯净度和防封能力是机房 IP 无法比拟的。

### Q2：使用原生 IP 还会被 Netflix 封锁吗？
正规原生住宅 IP 几乎不会被流媒体封锁。即使偶发平台更新规则，服务商也会在后台自动轮换新的纯净 IP 池，保障用户长期畅看。
