## 四、如何突破客户端本地吞吐瓶颈

如果你发现自己的千兆梯子在客户端里只能跑 100Mbps，请排查以下本地设置：
1. **客户端内核类型**：确保开启了 **TUN 模式**，并使用较新的 **Mihomo (Clash Meta)** 核心，其针对多核 CPU 进行了并行加解密调度优化；
2. **Wi-Fi 协商速率**：连接 5GHz Wi-Fi 或使用六类千兆网线直连路由器，避免 2.4GHz Wi-Fi 的物理传输瓶颈；
3. **关闭安全软件实时流量扫描**：部分杀软会拦截并逐包解密代理流量，造成严重的 CPU 瓶颈。

## 五、大带宽机场常见问题解答 (FAQ)

### Q1：测速跑出 500Mbps，是不是意味着我日常用流量会成倍消耗？
不会！流量消耗只取决于你**下载或观看了多少实际体积的数据**。例如看一部 10GB 的电影，无论网速是 10Mbps 还是 500Mbps，消耗的流量都是 10GB。大带宽的优势在于**大幅缩短了加载缓冲时间，让等待彻底归零**。

### Q2：单线程带宽和多线程带宽有什么区别？
Speedtest 测速默认采用多线程（Multi-Connection），容易跑出很高的数字；但日常看网页、看流媒体视频时，往往依赖**单线程下载速率（Single Connection）**。劣质机场多线程能跑 100Mbps 但单线程只有 2Mbps；正规 IEPL 专线机场单线程即可突破 80Mbps+，体验差异巨大。
