# 关于我们 (About Us)

**tizituijian.world（梯子推荐网）** 是一家专注于跨境网络加速、代理协议安全与网络服务商可靠性评测的独立技术研究团队。

在鱼龙混杂的代理服务市场中，充斥着大量虚假测速截图、高额返利诱导、虚标带宽倍率以及频繁“跑路”的劣质服务。我们的立项初衷非常明确：**通过严谨的工程化测试、真实的三网晚高峰网络压测与长周期可用性追踪，为需要跨境办公、学术科研、跨国开发及多媒体娱乐的用户提供具备真实参考价值的选型决策指南。**

## 一、团队背景与专业资质

我们的核心评测团队由资深网络安全研究员、前跨国企业网络架构师以及开源代理协议贡献者组成：

为确保所有评测数据的真实性与可复现性，我们自建了跨省份、多运营商的分布式测试节点：

| 接入网络 | 本地物理接入环境 | 骨干网路由特征 | 测试设备终端 |
| :--- | :--- | :--- | :--- |

| **中国联通 (China Unicom)** | 北京千兆 FTTH (1000M 下行 / 100M 上行) | AS4837 / AS9929 (联通A网) | ThinkPad X1 / Ubuntu Server |

所有测速与延迟测试均避开本地无线干扰（采用全双工 Cat6A 六类千兆网线直连路由器），并在每天 **20:00 - 23:00（全国骨干网晚高峰）** 执行至少 50 次并发吞吐压力测试。

## 三、我们的核心评测原则

### 1. 绝对的实测优先
我们拒绝任何仅凭品牌方宣传文案撰写的“云评测”。全站收录的每一个梯子与机场品牌，均经过团队自费购买账号、在不同宽带环境下进行至少 14 天的连续挂机监测。

### 2. 差评敢说，曝光陷阱
如果某家服务商晚高峰丢包率超过 15%、流量倍率暗中克扣、或者出现工单数天不回的情况，我们会在评测页面明确予以警示并下调推荐评级，绝不因商务关系掩盖真实使用缺陷。

### 3. 数据透明，开源方法论
我们公开所有的测试维度、测速工具版本与评分权重（详见 [评测方法论](/methodology)）。任何读者与同行均可依照相同标准进行复测验证。
