## 四、保护个人隐私的四大实战防御法则

1. **绝对不在 HTTP 明文网页输入密码**：注意看浏览器地址栏是否有「小锁」标记。如果网站显示「不安全（HTTP）」，数据在传输过程中是明文的，存在被中间人窥视风险；
2. **在客户端启用 ECH（Encrypted Client Hello）**：现代代理客户端支持 ECH 加密，可将访问的域名 SNI 也彻底加密，让中间节点连你访问了什么域名都无法知晓；
3. **开启 DNS over HTTPS（DoH）**：防止本地运营商通过 DNS 查询窥探你的上网轨迹；
4. **为不同服务设置独立高强密码**：使用 1Password 或 Bitwarden 等密码管理器。

## 五、隐私安全常见问题解答 (FAQ)

### Q1：使用无痕模式（Incognito）能防范机场主审查吗？
不能！浏览器的「无痕模式」仅仅是不在本地电脑上保存历史记录、Cookie 和缓存文件；但网络请求依然会正常发出，并经过代理节点向外传输。无痕模式防的是「借你电脑看的人」，防不了网络层节点。

### Q2：使用开源客户端比自研客户端更安全吗？
从代码透明度角度看，开源内核（如 Mihomo）经过全网极客审计，确实不存在后门；但对于正规老牌大厂（如光速云）的自研客户端，其同样受商业信誉约束。关键在于**服务商本身是否信誉可靠，而不是单纯纠结客户端的形态**。
