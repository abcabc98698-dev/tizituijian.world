## 四、排查节点失效的 3 步快速自检法

当你在客户端看到所有节点突然全部变红（Timeout）时，按以下顺序排查：
1. **检查本地系统时间**：Windows / Mac 系统的本地时间如果与网络标准时间相差超过 60 秒，VMess/VLESS 协议的时间戳鉴权会直接失效；
2. **测试本地网络连通性**：关闭代理，测试百度能否正常打开，排除本地宽带断网问题；
3. **一键更新订阅链接**：在客户端右键订阅，选择「更新订阅」。如果是优质专线机场，后台更新后会自动拉取最新的可用节点列表。

## 五、节点失效常见问题解答 (FAQ)

### Q1：为什么免费节点通常在晚上更容易失效？
因为晚上 20:00~23:00 是网络流量的高峰期，防火长城（GFW）的动态审查算法在晚高峰会调高敏感度阈值；同时，免费节点被海量并发用户同时挤占，容易触发境外 VPS 厂商的 CPU 满载告警或被封禁端口。

### Q2：专线机场真的完全不会被封锁吗？
正规 IEPL/IPLC 物理专线是向中国境内正规基础电信运营商租赁的企业跨境专用传输通道，其传输数据在物理光缆的二层封装内点对点流动，不走公网路由，**物理上不存在被公网防火墙拦截封锁的可能**。
